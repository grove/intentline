# Advisory child handoff

`slice export --work WORK --child S1 --out NEW_PRIVATE_DIR --json` explicitly
publishes source-bound advisory input. `slice inspect --bundle DIR --json` checks
it offline through installed trusted code. A bundled `inspect_child.py` can also
be run with `python -I -B`, without importing Intentline. Do not execute scripts
from an untrusted bundle: use the installed inspector to inspect its data.

Each flat package contains exact parent contract/history, whole allocation,
selected child view, every original constraint/exclusion, prerequisite outcomes,
all parent final-check owners, source captures and full archived continuity.
`slice-manifest.json` is the canonical digest inventory written last. Extra files,
unsafe references, partial outputs, altered inherited obligations and missing
ancestors refuse. Unknown keys/duplicate JSON fields and noncanonical bytes refuse.
This is a frozen snapshot; offline inspection cannot establish live filesystem
freshness after export. Re-export requires current parent/source/plan validation.

The child is an advisory acceptance contribution. Parent adoption does not approve
child scope, a decomposition, implementation or dispatch. Markers and inspections
say authorization/child_acceptance not_established, consumer_execution not_observed,
and structurally_validated/semantics unverified. Gaps remain explicit; they do not
turn this advisory package into a ready standalone agreement. Optional private
reports and raw adoption/approval material are omitted.

Proofline's current optional JSON adapter accepts only one original request and
an initial schema-1 contract; child bundles are unsupported. Its former direct
and native controllers are historical. This bundle has no shortened source.md,
direct brief or native-manifest.json. A future child adapter needs a separately
tested consumer change preserving complete parent source, inherited constraints,
prerequisites and integration obligations. Child successes cannot prove parent
success. No child adapter or live consumer/model invocation is supplied here.

Intentline remains independent of Lore, Proofline and P2P. Humans and existing
agents can consume advisory data without any of them installed. No issue tree,
tracker writes, agent controller, inference or implementation/proof runner is added.
