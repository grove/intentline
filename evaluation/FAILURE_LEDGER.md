# 0.2 failure ledger

These six adverse before/after plans are authored development probes. They are
not observed baseline agent failures, authenticated reviews or pilot results.
No real-model failure rate or prompt improvement is inferred. Original 0.1
examples, snapshots and adverse outputs remain unchanged. No holdout is registered
or read. Every meaningful clarification below is tied to a reproducible source,
exact before/after template digest and authored finding in semantic-probes.json.
Prepare binds that template to the actual frozen source bundle; tests bind the
finding as a self_check against that exact bad draft without implementing it.

| Probe | Failure | Smallest instruction clarification |
|---|---|---|
| 02-oracle | Candidate called again to compute its own expected result | State the source-derived expected answer and a counterexample before choosing a check |
| 02-exclusion | Explicitly excluded dashboard becomes mandatory | Trace exclusions as well as obligations; optional advice cannot bind |
| 02-exception | Proposed global policy replaces accepted staging exception | Carry lifecycle plus general rule and exact exception scope together |
| 02-no-harness | Settled rejection becomes an outcome question | Separate missing observation from unknown product behavior |
| 02-report | Historical report/rejected approach becomes current runtime authority | Code/report observations cannot establish policy or execution proof |
| 02-ceremony | Boundary variations duplicate one promise | Use one outcome row with related boundaries; no extra mandatory stages |

Skill wording already addressed many of these in 0.1. The 0.2 changes make the
concrete traps explicit; no schema expansion or heuristic semantic validator is
justified. Tests demonstrate record/audit mechanics and byte bindings, not that
an arbitrary agent will reason correctly. Costs/latencies are unknown. External
failures, when available, must be appended with task/source/plan revision and
reviewer provenance rather than replacing these fixtures or tuning holdout gold.
