## Gates before any separately authorized experiment

1. Resolve request edit history, historical accepted/proposed authority, source
   scope and issue-prose reuse rights. Retain every source and rejection. Derive
   corrected gold from originals alone, preserve original ledgers/challenges and
   each source-grounded resolution. No unresolved challenge becomes a clean case.
   The host builds one exact ordered corpus per task; no solution, answer, grading
   hint, private critique or task-specific skill advice enters it.
2. Obtain an actual model/provider grant, dollar or explicit subscription bound,
   overall time/call cap, allowed hosts/sources/models and separate stage budgets.
   No ambient credentials, subscription or engineering/PR permission is a grant.
   Unspent allowance never permits adding tasks/models/retries.
3. Provision actual role-specific read-only mounts/users/containers and separate
   write scratch. Deny gold/other sessions/operator answers/unauthorized network
   and connected apps on every surface, not only shell. Run the access canaries
   with trusted host policy/denial witnesses before each role's inference.
   Different folders/threads/subagents are not isolation. A failed or unresolved
   surface stops qualified comparison; preserve the original attempt.
4. Freeze two correct controls and all eight seeded fault categories **per task**,
   rules/rubric/model and expected answers privately. Register them before two
   fresh calibrated blind sessions. Run only with the bounded grant. Full fixed
   population, all critical seeds found and no valid-alternative rejection are
   required. Failed calibration is a reliability finding, never repaired silently.
5. Pre-register three tasks from three projects × three arms. Freeze complete
   ordinary/Intentline/P2P instruction trees, exact sources, model/version/reasoning,
   tools/delegation, actual host scopes, arm order, horizons, max calls, budget,
   retry/stop/normalization rules and every task-arm/blind assignment. Retain the
   sealed registration hash separately from the study files. No formal 0.5
   registration or eligibility record changes.
6. The trusted host dispatches three fresh top-level planning sessions for the
   first task. Check identity/isolation/mechanical blockers and stop without
   replacing it if a gate fails. If healthy, dispatch the remaining six attempts
   within the original caps. Retain every refusal, timeout, interruption, partial
   output, denial and manual intervention; no surprise retries or hidden calls.
7. Seal raw responses/transcripts/native configuration/usage. Import lossless
   format-neutral plans and private label mappings; never add missing material.
   Score in fresh output-specific source/neutral/rules-only contexts tied to the
   two calibrated profiles. Capture exact scopes again before judging. Retain all
   disagreements, bidirectional mappings, counterexamples and contrary findings.
8. Inspect the imported packet through the read-only adapter with the external
   registration pin. Publish only reviewed source-safe aggregates. Report paired
   task differences before aggregate counts, all failed-assignment denominators,
   preparation/judging/planning overhead and null unknowns. No three-task or
   six-to-nine-task diagnostic establishes broad or independently human efficacy.

Stop decisions are insufficient_or_unqualified_evidence, fix_specific_defect,
simplify_overhead or expand_new_tasks. Expansion requires a new registration and
remaining explicitly approved budget; cases exposed to tuning stay development.
Optional slicing is separately not_run unless credible parent contracts, source
separation and a grant exist. Use slicing_04/rubric_04 unchanged, preserve NO SPLIT
and integrated-parent responsibility; child success is not parent proof.
