# Authored access controls

`access_canaries.py` contains operator-only standard-library sample probes.
Its unit tests are public authored fixtures, not historical task requests,
private gold, measured model predictions or observed host capability evidence.
It launches no models; network/app probes require separate explicit host preflight
scope. The read-only evaluation adapter must never call these helpers.

Use only nonsecret synthetic sentinels. Missing paths/endpoints/tools are unresolved;
sample denials never establish whole-environment qualification. See
`../../AGENT_ACCESS_06.md` for trusted host inventories, actual dispatch/mount
evidence and stop rules. Keep all real receipts and paths private.
