# Separate blinded slicing rubric, revision 1

Use the same private-source/provenance, matched-arm and two-blinded-scorer
conventions as rubric_02. Judge substantive source-to-output mappings, not plan
length or ticket count. Every score binds opaque blind ID, exact output digest,
reviewer, offset timestamp, blinded true, conflicts and original source citations.
Retain both reviewers; per assignment adverse totals use the greater count.

Mandatory nonnegative adverse counts:

| Dimension | Finding |
|---|---|
| false_positive_splits | Extra delivery cycles without a justified observable boundary |
| missed_necessary_splits | A concrete compatibility/recovery/ownership boundary was missed |
| lost_parent_requirements | An original parent promise was silently narrowed or omitted |
| invented_child_obligations | A child adds unsupported outcome or speculative enabling work |
| constraint_leakage | Security, compatibility, exclusions or scoped exceptions were lost |
| missing_parent_integration | No owner/evidence for assembled behavior, negative cases or shared state |
| prerequisite_errors | Missing, false or cyclic dependencies; closure treated as observed outcome |
| avoidable_verification_cycles | Credible merges would eliminate unnecessary complete cycles |
| weak_oracles | Candidate-derived expected results or child success substituted for parent proof |
| missing_gap_disclosures | Unavailable observation paths or uncertainty were hidden |

Observe actual preparation, actions, elapsed time, model calls, tokens/cost and
independent downstream outcomes only when separately available and authorized.
The standard nullable usage metrics include preparation; unknown values remain
null. Downstream independent outcomes need separate frozen candidate/review/proof
receipts and a separately registered analysis, never inference from plan shape.
No advantage is assumed from more children or longer plans. Development examples
are authored regression probes, excluded from empirical denominators. The real
pilot/holdout remains unrun and untouched until human and host prerequisites exist.
